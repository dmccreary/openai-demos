# MicroSim Library

Explore interactive, browser-friendly simulations that accompany the documentation site. Each MicroSim lives inside `docs/sims/<name>` and can be embedded elsewhere via iframe.

## Available MicroSims

- [Bouncing Ball with Elasticity](bouncing-ball-with-elasticity/index.md) – Adjust elasticity to see how collision energy affects bounce height, hang time, and direction changes.
